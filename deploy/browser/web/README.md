# m.ai — in your browser

A from-scratch language model (potus-chat, 16M params, trained on a MacBook)
converted to ONNX and running **100% client-side** — the model downloads once,
then every reply is computed in your browser with no server call. Works offline
after the first load.

It is a potato. Confidently wrong, and entirely yours.

Source + training pipeline: https://github.com/mohith2309/m.ai
